# Переменные окружения

## Принцип разделения ролей
| Артефакт                         | Аудитория           | Назначение                                    |
| -------------------------------- | ------------------- | --------------------------------------------- |
| `.env.example`                   | DevOps, разработчик | Справочник для деплоя и шаблон для `.env`.    |
| `README.md` (в папке приложения) | Разработчик         | Инструкция для настройки локальной разработки |


## Доп. правила
- Не ослаблять валидацию в коде ради удобства dev — это скрывает ошибки при деплое.
- Не дублировать инструкции по настройке: dev → README, deploy → `.env.example`.
