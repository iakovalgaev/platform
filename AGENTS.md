# Platform
Сервисы, общие для нескольких проектов. Каждый сервис — приложение в `apps/*`, деплоится отдельно, своей БД нет, пока она не понадобится. Готовые образы с конфигами без своего кода — в `infra/*`. Монорепо pnpm + turbo, fastify, biome.

## Сервисы
- `apps/tribute-router` — принимает вебхуки Tribute и пересылает их проекту-владельцу товара.

## Правила кода
Работая с кодом, следуй `docs/code-gen/core.md`. Логи, переменные окружения и тесты — `docs/logging.md`, `docs/env-variables.md`, `docs/testing.md`.

## Git
Коммитить в `main` можно; без `--no-verify`, `push --force`, `reset --hard`.
Заголовок коммита — `T-123: текст`, тикет совпадает с веткой `T-123`.
В сообщения коммитов и описания PR не добавляй `Co-Authored-By`.
